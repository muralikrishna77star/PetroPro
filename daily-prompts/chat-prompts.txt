==================================================================
 DAILY CHAT PROMPTS LOG
==================================================================

 Purpose:
   Keep a running record of the chat prompts you use each day so you
   can pick up where you left off the next morning.

 How to use:
   1. Auto-export (recommended): run the exporter to pull your real
      Copilot chat prompts into this file under a dated header.

        - PowerShell:  ./daily-prompts/export-prompts.ps1
        - Or Python :  python ./daily-prompts/export_prompts.py

      Options:
        ./daily-prompts/export-prompts.ps1 -Date 2026-07-11   # a specific day
        ./daily-prompts/export-prompts.ps1 -Days 3            # last 3 days

      Re-running for the same day is safe: it refreshes that day's
      block instead of duplicating it.

   2. Manual: add your own notes/prompts under today's date header
      using the template block below.

 Tip: Start each new day by reading the most recent date block to
      recall where you stopped and which prompt to continue with.

==================================================================
 TEMPLATE (copy for manual entries)
==================================================================
 ----- YYYY-MM-DD -----
 [HH:MM] prompt or note
 NEXT STEP: what to start with tomorrow
