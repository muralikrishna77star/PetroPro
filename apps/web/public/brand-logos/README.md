# Oil company logos for receipts

Printer Settings → Receipt content → Oil company loads the logo for the chosen company from this folder.
Each outlet uses its own company's logo, as its dealership allows.

| Company | File |
| ------- | ---- |
| Indian Oil (IOCL) | `iocl.png` |
| Hindustan Petroleum (HPCL) | `hpcl.png` |
| Bharat Petroleum (BPCL) | `bpcl.png` |

`.jpg`, `.jpeg` and `.webp` work too. Use the official artwork, on a white or transparent background, at
least 256 pixels wide. The printer has only black: dark colours (navy, blue, red) print solid and light
ones (orange, yellow) drop out to white, so check the preview in Printer Settings after changing a file.

A logo already chosen is stored with the outlet's receipt settings, so replacing a file here changes
receipts only after the company is chosen again and saved.
